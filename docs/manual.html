面に沿ってスライド（プロポーショナル）

選んだ頂点を、顔の面から浮かせず・めり込ませずにすべらせる Blender のアドオンです。まわりの頂点も、プロポーショナル編集と同じように少しずつついてきます。口を開ける・口角を上げるといった表情のシェイプキー作り向けです。

1. 3 ステップで使う

  1. 編集モードで、動かしたい頂点を選ぶ。
    シェイプキーの一覧で、書き込みたいキー（ベースではないキー）を選んでおきます。キーがまだ無いときは、N パネルの「新しいキーを作って始める」が便利です。
  2. マウスを 3D ビューの上に置いて Shift + Alt + V。
    右クリックのメニュー（いちばん下）や、ヘッダーの「頂点」メニューからも始められます。メニューから選んだときはカーソルが十字になるので、動かし始めたい所をクリックします（英語で Input pending と出ている間はクリック待ちです）。
  3. マウスを動かして、左クリックで確定。
    やめるときは右クリックか Esc。操作中は Shift + Alt + V をもう押さなくてかまいません。キーを押すたびに動かし方を変えられます（操作中のキー）。

右クリックメニュー（頂点を選ぶモード）のいちばん下。

ふつうの G（プロポーショナル編集つき）に近い感覚で使えます。ホイールで範囲、XYZ で軸、数字で数値入力。違うのは、動いた頂点が面の上に乗ったままになることと、F B M A がこの道具だけのキーなこと、R（回転）の軸がはじめは「面の向き」なことです。Ctrl を押しながらのスナップ、中ボタンで軸を決める操作は使えません。

2. 始める前に：書き込み先のキー

動かした結果は、編集モードでいま選ばれているシェイプキー（一覧で青くなっているキー）に書き込まれます。シェイプキーが 1 つも無いメッシュでは、メッシュそのものを動かします。

次の 2 つのときは、動かす前に止まって、画面の下に理由が出ます。

止まるときなぜ直し方
書き込み先がベース（Basis）で、ほかにも表情キーがあるベースを動かすと、ほかの表情キーも全部いっしょに変わってしまうためシェイプキーの一覧で書き込みたいキーを選ぶ。新しく作るなら「新しいキーを作って始める」
書き込み先のキーがロックされている鍵をかけたキーを守るため一覧でそのキーの鍵のアイコンを外す

シェイプキーがベース 1 つだけのときは止まらず、ベースそのもの（元の顔）を動かします。表情キーを作るときは、先に「新しいキーを作って始める」でキーを足してください。

操作中も、ヘッダーに「書き込み先：キーの名前」がずっと出ています。違うキーに書いていないか、ここで確かめられます。

5. 範囲の決め方

  • 操作中にホイールを下へ回すと広く、上へ回すと狭くなります（Blender の G と同じ向き）。Shift を押しながらだと少しずつ変わります。
  • 目安は、動かしたい部分の幅くらい。口を開くなら口の幅、口角を上げるなら口の幅の半分〜同じくらいから始めて、ヘッダーの「影響 ○ 頂点」と点の色を見ながら直します。
  • 範囲の半径は Blender のプロポーショナル編集のサイズと共通です。確定すると、その半径が次も使われます。

始めたときに半径が勝手に変わるとき

前に別のモデルで使った半径がそのまま残っていると、顔に比べて大きすぎたり小さすぎたりします。始めたときに半径が次のどちらかなら、選んだ頂点に合った大きさ（選んだ範囲の半分か、まわりの辺の長さの 6 倍の、大きいほう）に直して始め、画面の下に「範囲の半径 ○ は大きすぎるので △ から始めます」と出ます。

  • 大きすぎる：直した大きさの 10 倍より大きい
  • 小さすぎる：選んだ頂点のまわりの辺の長さの平均より小さい

この道具で最後に確定したときの半径か、N パネルの「範囲の半径」で決めた半径のままなら、大きくても小さくてもそのまま使います（わざと決めた大きさを勝手に変えないため）。

6. 設定の意味と、いつ変えるか

減衰（Shift + O）

範囲のふちに向かって、ついてくる量がどう減るか。横が選んだ頂点からの距離（左が 0、右が範囲のふち）、縦がついてくる量です。迷ったら「スムーズ」。

スムーズなめらかに減る（迷ったらこれ）
球状ふちの近くまでしっかり動き、ふちで止まる
ルートふちの近くまでよくついてくる
逆二乗球状より少しやわらかい
シャープ選択のすぐ近くだけ動く
リニア距離に比例して減る
一定範囲の中は全部同じだけ動く（ふちに段差）

Blender の減衰の「ランダム」は使えないので、選ばれていたときは「スムーズ」で動かします。確定すると、Blender のプロポーショナル編集の減衰も「スムーズ」に変わります。

つながった面だけ（Alt + O、はじめは ON）

ON のときは、メッシュの辺をたどった距離で範囲を決めます。上唇を動かしても、すぐ下にある下唇は、口の切れ目の向こう側（たどると遠い）なので動きません。OFF にすると、まっすぐの距離で決めます。Blender の「接続のみ」と同じ考え方です。

面に沿わせる（F、はじめは ON）

ON のときは、動いた頂点を面の上に乗せたまま、面に沿ってすべらせます。顔から浮いたりめり込んだりしません。OFF にすると、ふつうのプロポーショナル移動と同じです（ヘッダーに ⚠ が出ます）。「う」のように唇を前へ突き出すときは OFF にします。

沿わせる面（B、シェイプキーに書くときだけ）

  • いまの形（ふつうはこれ）：始めたときの形の面に沿ってすべらせます。
  • ベースの形：ベース（Basis）の面に沿った向きで動かし、その動きをいまの形に足します。同じキーを何度も直して形がゆがんできたとき、ゆがんだ面に引っぱられないようにするためのものです。

F9 のパネルに、ベースの形として使っているキーの名前（ふつうは Basis）が出ます。

左右対称（M）

選んだ側の動きを、反対側（ローカルの X の符号が逆の側）にも鏡に写したように動かします。はじめは、メッシュの「X ミラー」（N パネルの「左右対称（X）」と同じもの）と同じ ON/OFF になります。真ん中の線の上の頂点は、左右にずれないように X を動かしません。

反対側の相手はベースの形で、ちょうど鏡の位置にある頂点を探して決めます。左右で形が違うメッシュでは見つからない頂点が出て、ヘッダーに ⚠ の数が出ます。数えるのは選んだ頂点だけなので、⚠ が出ていなくても、まわりのついてくる頂点の左右の形が違うと、動きはぴったり左右対称にはなりません。

回転（R）

選んだ頂点の真ん中を中心に、マウスを中心のまわりに回すと回ります（中心からマウスへ点線が出ます）。選んだ頂点は面に沿って回り、まわりの頂点は、ついてくる量に合わせて少しだけ回ります。眉・まぶた・口角の傾きを変えるのに向いています。

  • 軸ははじめ「面の向き」：選んだ所の面に垂直な軸のまわりに回します。斜めから見ていても、頂点が顔の上でその場で回るので、浮いたりめり込んだりしません。回転中にもう一度 R を押すと「画面の奥向き」（ふつうの R と同じ）に切り替わります。
  • X Y Z で、その軸のまわりに回せます。ただし軸が面に寝ていると（たとえば正面を向いた顔で Y 以外）、面に沿ってはほとんど回らないので、ヘッダーに ⚠ が出ます。
  • 大きく回しても、中心へ縮みません（角度を刻んで弧の上を歩かせています）。
  • 左右対称（M）と組み合わせると、反対側は逆向きに回ります。中心はそれぞれの側の真ん中です（両側を選んでも、片側ずつ回ります）。困り眉・怒り眉が一度で作れます。
  • 数字を打つと度で回ります（15 で 15°）。軸が手前を向いているとき、プラスは画面で左回りです。

口を開く（A）

唇の切れ目のまわりの頂点を選んで A を押すと、選んだ頂点を「上唇」「下唇」「口角」に分けます。マウスを下へ動かすと、下唇がついてきて、上唇は少しだけ反対（上）へ動きます。口角は動きません。

  • 上唇の割合（はじめは 0.25）：下唇の動きに対して、上唇がどれだけ反対へ動くか。0 なら上唇は動きません。
  • まるく開く（はじめは ON）：口の真ん中ほど大きく開き、口角に向かって小さくなります。OFF にすると全体が同じだけ開きます（四角い口）。

上下の分け方は、始めたときの画面の上下で決まります。正面（テンキー 1）から見て始めてください。

7. はじめの設定と、何が残るか

N パネル（N）の「面スライド」タブ。編集モードのときだけ出ます。

  • スライドを始める：押したあと、動かし始めたい所をクリックします。
  • 選択中・書き込み先：始める前の確かめ用。止まる条件のベースが選ばれていると印と直し方が、ロックしたキーなら「ロックされています」の印が出ます（鍵はシェイプキーの一覧で外します）。
  • 新しいキーを作って始める：押したあと、動かし始めたい所をクリックすると、「新しい表情」という名前のキーを作って（ベースが無ければベースも作って）、値を 1 にしてから始めます。右クリックや Esc でやめると、作ったキーは消えます（空のキーは残りません）。名前はあとでシェイプキーの一覧でダブルクリックして変えます。
  • はじめの設定：操作を始めたときに使う設定。操作中のキーで変えても、その回だけで、ここは変わりません。ただし「範囲の半径」と「減衰」だけは Blender のプロポーショナル編集の設定そのものなので、確定すると操作中の値に置き換わります。
  • 使い方を開く（右上の ? も同じ）：このマニュアルを開きます。

何が残るか

設定どこに残るか
範囲の半径・減衰Blender のプロポーショナル編集と共通。確定すると、そのときの値が残ります（操作中に変えた値、始めたときに自動で直された半径、ランダムの代わりのスムーズも）。ふつうの G のプロポーショナル編集にも使われます。やめたときと、F9 で変えたときは残りません
左右対称（X）メッシュの X ミラーの設定そのもの。操作中の M では変わりません
つながった面だけ・面に沿わせる・沿わせる面・上唇の割合・まるく開くこのシーンの「はじめの設定」として .blend に保存されます。操作中のキーで変えても、その 1 回だけ
軸・動かし方（移動／拡大縮小／口を開く）残りません。毎回「移動・軸なし」から始まります

8. あとから数値で直す（F9）

確定したあと、左下の「面に沿ってスライド」を開くか F9。いちばん下の「左右対称（X）」がうすく見えることがありますが、押せます（画面の下のほうで F9 を押すと、パネルの高さが足りずに最後の行がうすく見えるだけです。マウスを画面の上のほうに置いて押すと直ります）。

確定したあとでも、左下のパネル（または F9）で、移動量・範囲の半径・減衰・左右対称などを変えると、動かす前の形からやり直して結果が変わります。マウスでは合わせにくい細かい量は、ここで数字を打つのが楽です。

F9 で変えた範囲の半径と減衰は、その 1 回の結果を変えるだけです。Blender の設定にも、次の操作にも残りません。

  • 移動量はワールド座標（口を開くときは下唇の動き）。
  • 拡大縮小のときは「倍率」と「拡大の中心」、回転のときは「角度」と「画面の奥向きで回す」。
  • 動かし方のボタンで、移動・拡大縮小・回転・口を開くを切り替えることもできます。
  • 上下の分け方や面の向きは、操作を始めたときの視点のまま計算します。

操作中に数値で入れる

操作中に数字を打つと、その量で動きます。Enter で確定、Backspace で 1 文字消します（Ctrl + Backspace で全部消します）。ヘッダーに「⚠ 読めません」と出ている間は確定できないので、Backspace で直してください。

打った数字は「動かそうとする量」です。面に沿わせる（F）が ON のときは面の上をすべるので、実際に動く量は少し小さくなります（曲がった所ほど小さい）。ヘッダーの「移動 ○」と F9 の「移動量」も、打った量のほうです。ぴったりの量で動かしたいときは F で OFF にしてください。

  • Z → 0.005 → Enter：Z（上）へ 0.005 m（5 mm）。単位系がメートル法なら、数字だけのときはいつもメートルとして読みます（長さの単位を cm にしていても同じ）。単位系が「なし」のシーンでは Blender の単位で読みます
  • Z → -0.005 → Enter：下へ 5 mm
  • A → 0.008 → Enter：口を 8 mm 開く（下唇が 8 mm 下がる）
  • S → 1.2 → Enter：1.2 倍に広げる
  • R → 15 → Enter：15° 回す（-15 で逆向き）
  • 単位を付けたいときは、先に = を押してから 5mm のように打ちます（= を押さずに m を打つと、M の左右対称が切り替わります）。

軸を決めずに数字を打つと、ふつうの G と同じく X の向きに動きます。

9. 表情キーのレシピ

どれも、はじめに正面から見て（テンキー 1）、書き込み先のキーを選んでから始めます。顔が左右対称なら、メッシュの X ミラー（N パネルの「左右対称（X）」）を ON にしておくと、片側だけ選べば済みます。

「あ」（口を開く）

練習用の板で口を開いたところ（A・まるく開く・範囲 3 cm）。

  1. 唇の切れ目のまわりの頂点を選びます。上唇の縁と下唇の縁を両方、口角まで。Alt + クリックのループ選択でぐるっと選ぶと楽です。
  2. Shift + Alt + V で始めて、A を押します。ヘッダーに「上唇 ○・下唇 ○・口角 ○」と出れば分けられています。
  3. マウスを下へ動かします。下唇が下がり、上唇が少し上がります。
  4. ホイールで範囲を口の幅くらいにします（狭すぎるとヘッダーに目安が出ます）。
  5. 左クリックで確定。上唇の動きが多すぎ・少なすぎなら、F9 の「上唇の割合」で直します。

口角を外へ広げたいときは、そのあと口角の頂点だけを選び直して、Shift + Alt + V → X で横へ動かします（左右対称が OFF なら M で ON）。

笑顔（口角を上げる）

  1. 口角の頂点を選びます（左右対称が ON なら片側だけ）。
  2. Shift + Alt + V で始めて、マウスを斜め上・外へ。
  3. 範囲は口の幅の半分くらいから。ほおまで持ち上げたいときは広くします。
  4. 左右がそろっていなければ M で左右対称を ON。

目を細める（下まぶたを上げる）

  1. 下まぶたの縁の頂点を選びます。
  2. 始めて Z を押し、上へ動かします。
  3. 「つながった面だけ」が ON なら、目の切れ目の向こうの上まぶたは動きません。上まぶたまで動くときは Alt + O を確かめます。
  4. 範囲は目の幅の半分くらいから。

困り眉・怒り眉（眉を傾ける）

  1. 片側の眉の頂点を選びます。メッシュの X ミラー（左右対称）を ON にしておきます。
  2. Shift + Alt + V で始めて R。左右対称が OFF なら M で ON。
  3. マウスを眉の真ん中のまわりに回します。眉頭が上がる向きなら困り眉、下がる向きなら怒り眉。反対側の眉は逆向きに回ります。
  4. 範囲は眉の長さの半分〜同じくらい。おでこやまぶたが動きすぎるなら狭くします。
  5. 角度を決めたいときは数字で（12 Enter など）、あとからは F9 の「角度」で直せます。

つり目・たれ目は、同じように上まぶたと下まぶたの縁（または目のまわり）を選んで回します。

ほおを上げる

  1. ほおの真ん中あたりの頂点を数個選びます。
  2. 始めて上へ。範囲は広め、減衰は「スムーズ」。
  3. 面に沿ってすべるので、ほおはふくらみません。ふくらませたいときは、F で面に沿わせるのを OFF にして前へ出すか、ほかの道具で足します。

11. できないこと・苦手なこと

  • 動くのはアクティブなオブジェクトだけです。複数のオブジェクトをいっしょに編集モードにしていても、ほかのオブジェクトは動きません（始めたときにお知らせが出ます）。
  • 左右対称は「位置」で相手を探します（Blender のトポロジーミラーは使えません）。ベースの形で左右がぴったり同じ位置の頂点だけが相手になります。
  • 前へ突き出す・へこませる動き（「う」「お」の唇、ほおのふくらみ）は、面の上をすべる動きではありません。F で面に沿わせるのを OFF にして動かします。
  • 沿わせる面は、選んだ頂点とつながっている面だけです。別のパーツ（離れたメッシュの島）の面には吸い付きません。
  • Blender の減衰の「ランダム」は使えません（「スムーズ」になります）。

12. 入れ方・更新・ショートカットの変え方

入れ方

  1. 配られた zip（proportional_surface_slide-2.1.0.zip）を、Blender の画面にドラッグ＆ドロップします。
    または、プリファレンス → Get Extensions → 右上の ∨ → Install from Disk… で zip を選びます。
  2. Blender 5.0 以上で動きます（5.2 で確かめています）。

更新

新しい zip を同じように入れると置き換わります。入れたあと、Blender を一度閉じて開き直してください（開いたままだと古いほうが動いていることがあります）。

ショートカットの変え方

  1. プリファレンス → キーマップ（Keymap）。
  2. 右上の検索を「名前」にして 面に沿ってスライド を探します。
  3. 出てきた行のキーをクリックして、新しいキーを押します。

Windows で、入力言語を Alt+Shift で切り替える設定にしていると、Shift+Alt+V が取られることがあります。そのときは上の手順で別のキーにしてください。N パネルの「ショートカット：」には、いま決まっているキーが出ます（キーマップで無効にしたときは「なし（キーマップで無効）」）。
